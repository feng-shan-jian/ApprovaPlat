# 组织主数据范围与部门关系写入契约

## 有权对象

用户、角色、部门分别在自己的服务和 XML 查询中取得数据范围内的对象。管理详情不能先执行数据范围探测再调用无范围详情查询。

- 用户管理详情使用 `selectUserByIdInScope`，复用用户详情映射，保留部门、角色、密码更新时间等已有字段。`selectUserById` 和 `selectUserByUserName` 仍供登录、当前用户及工作流等既有内部读取使用。
- 角色、部门管理详情由现有 `selectRoleById`、`selectDeptById` 返回带范围的完整详情。部门详情仍包含 `parentName`。
- 批量用户、角色删除先按 ID 集合装载所有目标；任一目标不存在或越权，整批不写入。管理员保护针对实际取得的对象执行。角色占用状态一次查询整个集合。
- 导入保持原有逐行成功／失败语义。用户详情和输入部门按集合带范围装载。每行账号存在性读取仅取得 ID／账号，用于区分不存在、已存在但越权及当前批次刚新增的账号；不再无范围装载用户详情。本批新建成功只记录新建事实；当后续重复行首次要更新该账号时，通过真实带范围查询取得更新对象，不能以创建成功代替更新资格。更新仍保留原部门，输入部门仍必须在权限范围内。
- 部门集合查询返回有权对象的子集，以便导入逐行报告错误；单条详情、排序、关系写入分别在写入前拒绝缺失目标。排序仅修改 `order_num`。

带 `@DataScope` 的方法首参数是现有 `BaseEntity` 子类。内部调用通过 Spring AOP 代理，保留 `PermissionContextHolder` 的当前入口权限过滤。调用者不能自行提供可信的 `params.dataScope`。五类范围、自定义范围合并、停用角色排除和管理员全部范围沿用现有切面语义。

## 部门关系事务

部门新增、修改／移动、删除都在服务事务中先执行 `lockDeptRelations`，随后当前读取得目标。该查询按主键顺序锁定 `sys_dept` 最小主键的记录；它是现有部门表的一条记录，并不装载或巡检整棵树。部门删除是软删除，因此互斥点不会被业务删除移除。部署已有部门基线，不额外增加锁表或状态表。

关系写入遵循同一顺序：

1. 取得上述数据库记录锁。
2. 当前读装载有权访问的旧部门。普通编辑沿用旧部门已锁定的父级与祖先关系，不额外要求原父级可见；只有父级实际改变时才装载有权访问的新父级，各实际需要的对象只读一次。新增只装载父级，删除只装载目标。
3. 根据新父级自身 ID 和 `ancestors` 拒绝移入自身或子孙。
4. 移动或停用时装载必要子树。停用包含正常子部门的节点会被拒绝。
5. 在同一事务中更新后代路径、自身以及启用时所需的上级状态；失败全部回滚。

并发交叉移动在第二个事务取得关系锁后，依据先手已提交的祖先路径作决定。新增也取得同一锁，因而要么被先手移动包含在后代中，要么使用移动后的父级路径。删除的子部门和用户引用查询使用 `FOR UPDATE` 当前读，并清理 MyBatis 查询缓存；即使外层 REQUIRED 事务已建立旧的 REPEATABLE READ 快照，也不能漏掉已提交的引用。删除与部门新增不会同时把已删除节点作为有效父级。普通名称编辑和排序不装载子树。

新增到停用父级仍拒绝；启用部门仍启用其祖先；停用部门不会停用祖先。原顶级部门 `parentId=0` 的编辑保持现有行为，提交的 `ancestors` 不作为关系事实来源。删除的“存在下级部门／存在用户”仍返回原警告码 601。

关系锁把低频部门关系写入串行化。以后增加直接写 `parent_id`、`ancestors`、状态或删除部门的入口时，必须进入相同服务事务和锁顺序；不能绕过它直接调用 Mapper。离线物理清理部门表需要停写，不能与在线关系写入并行。

## 恢复

本次没有表结构、存储格式或外部 HTTP 参数迁移。服务、接口、Mapper、Controller 必须一同发布或回退；不支持混合新旧关系写入版本同时运行。回退代码不需要数据还原，成功移动仍是合法原格式祖先路径；失败事务没有残留部分写入。回退旧实现会同时失去本次服务端循环与并发防护。

## 部门与菜单树返回

正式查询先完成数据范围、权限过滤和排序；组装按 parentId 分组，保持输入对象、根和同层顺序，不改接口字段。编辑树把父 ID 不在本次输入的节点作为根，无根时返回原平面列表；授权路由只从明确父 ID（通常为 0）展开，不提升孤立节点。每次组装先清空 children，防止对象复用后的权限裁剪泄漏旧子项；不可达闭环不连接为循环对象。

TreeSelect 保留 id/label/disabled/children；菜单路由保留目录/页面/按钮过滤、隐藏、缓存、参数、内链和组件转换。部门管理仍返回平面列表，关系合法性由上述事务写入口维护。无表结构或接口迁移。
