# BPMN 设计器独立视觉规格

## 目标与视口

- 面向审批管理员和流程建模人员，采用克制、密集、可重复操作的桌面工具界面。
- 验收视口为 `1440x900` 和 `1920x1080`，产品最低支持宽度为 `1366px`。
- 不提供移动端 BPMN 编辑器；低于最低宽度时保持工作区固定最小宽度并由页面容器承接滚动。

## 工作区结构

| 区域 | 规格 |
| --- | --- |
| 页面标题 | 高度约 54px，显示模型名称、模型 key、版本和部署状态。 |
| 顶部工具栏 | 固定 48px，左侧文件与历史命令，中部布局、模拟和校验，右侧问题、设置、属性栏和保存。 |
| 左侧 Palette | 使用 BPMN 原生图标，紧贴画布左上方，不增加装饰卡片。 |
| 中央画布 | 占据剩余空间，浅色背景为近白，深色背景为中性黑灰；网格间距 20px。 |
| 右侧属性栏 | 固定 320px，可折叠；标题 46px，正文独立滚动。 |
| 小地图 | 右下角，距边缘 10px，不遮挡属性栏和主要建模路径。 |

## 视觉语言

- 使用平台既有 Element Plus 字体、间距和颜色变量，避免单独加载外部字体造成管理端割裂。
- 卡片圆角不超过 6px；工作区仅有一层边框，不嵌套装饰卡片。
- 主要颜色保持中性灰和白，蓝色仅用于选择、主按钮和活动状态；错误、警告分别使用平台红色和黄色语义色。
- 不使用渐变背景、装饰光斑、插画或营销式大标题。
- 工具按钮优先使用熟悉图标并提供悬停说明；导出、预览和布局多选项使用下拉菜单。

## 交互与稳定尺寸

- 圆形工具按钮固定 `32x32px`，工具栏高度和布局不因加载、问题数或选择状态变化而跳动。
- 画布和属性栏均使用 `minmax(0, 1fr)` 约束，长元素标识省略显示，表单控件不得撑破属性栏。
- 保存期间移除输入焦点，并以 `inert` 锁定画布和属性栏，防止序列化快照与后续修改竞态。
- 至少选择两个图形时启用对齐，至少三个图形时启用等距分布。
- Token 模拟运行时必须明确显示活动状态并禁用建模能力；退出后恢复 Palette 和 ContextPad。

## 验收要点

1. 两个目标视口均无工具栏文字裁切、按钮重叠、属性栏遮挡和小地图溢出。
2. Palette、ContextPad、Lint 标记、Token 动画、选择框和连线在浅色与深色主题下均清晰可见。
3. 打开 XML/JSON 预览、校验结果和设置抽屉时，弹层不超出视口且正文可滚动。
4. 属性栏折叠后画布立即获得完整剩余宽度，居中和缩放功能仍准确。
5. 导入、清空、保存和设置写入期间有稳定加载或确认状态，不出现可重复提交窗口。
