# WorkflowTaskCompletionApplicationService

## 作用

该服务是普通任务和受控多实例任务完成的唯一应用事务入口，保留部署表单校验、附件投影与绑定、抄送计划、动态下一办理人、动态多实例 revision、受控循环、结构化审计和写后对账。

## 写入顺序

1. 活动任务、实例、办理人和委派状态校验。
2. 一次读取 BPMN 与部署表单，校验变量并准备附件、抄送和后继办理计划。
3. 先占用 Flowable 多实例 revision。
4. 写循环路由、审计、附件绑定和表单提交快照。
5. 调用 Flowable `complete`，立即执行轮次写后对账。
6. 应用下一办理人并持久化抄送。

普通任务没有 `expectedRevision` 时继续使用原冲突契约；动态多实例在事务提交阶段出现乐观锁时继续附带既有 revision 冲突子码。
