# 本机账号与随机密码记录

本目录用于集中记录本机开发、联调、集成测试和发布彩排所创建或重置的账号。任何执行人或自动化只要生成了
账号或随机密码，都必须在同一操作阶段完成记录，不能只保留在终端输出、聊天记录、日志或命令历史中。

- 真实账号与随机密码统一写入 `accounts.local.md`；文件不存在时先创建，再执行需要该凭据的后续步骤。
- `*.local.md` 已由根目录 `.gitignore` 忽略，禁止加入 Git、构建产物或发布包。
- 每条记录必须包含创建时间、系统、主机、账号、权限范围、用途和清理状态。
- 账号发生轮换、禁用或删除时必须同步更新本地记录。
- 正式环境凭据仍由受控密钥或环境文件管理，本目录只保存当前工作机需要保留的测试记录。

每条记录至少使用以下字段：

```markdown
## <系统或服务名称>

- 创建/重置时间：<Asia/Shanghai 时间>
- 环境与主机：<环境、主机、端口或连接目标>
- 账号：<账号>
- 密码：<随机密码>
- 权限范围：<角色、数据库授权或可访问资源>
- 用途：<联调、集成测试或发布彩排>
- 状态：<启用、已轮换、已禁用或已删除>
- 备注：<轮换原因、关联任务或清理计划>
```

提交代码前必须运行 `git check-ignore testcount/accounts.local.md`，确认真实凭据文件仍处于忽略状态；同时检查
`git status`，确保没有其他包含凭据的文件进入待提交范围。
